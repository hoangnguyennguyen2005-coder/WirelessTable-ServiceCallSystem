# PBL4 principles
Draft 0.1.0, 2026-11-06; derived from supplied requirements, not independently ratified.
1. Concept C, offline PC authority; firmware pins/radio settings not invented.
2. Transactional persistence and correlation protect duplicate/restart/concurrent actions.
3. Device delivery, manager ACK and applied LED are distinct facts.
4. No web staff DONE; physical event/simulator only. Demo/hardware isolated.
5. Verify software with real checks; do not claim unmeasured hardware behavior.
User instructions govern changes; preserve traceability in docs/tasks.md.
